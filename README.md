# Julian Merchan

Estudiante de Ingeniería de Software en Bogotá, enfocado en backend con Python y aprendiendo a moverme cómodo en frontend (React/Vue). Actualmente en práctica en un proyecto de analítica para punto de venta en el sector farmacéutico, donde termino tocando desde sincronización de datos hasta el dashboard que los muestra.

## Lo que he construido

**[AURA](https://github.com/Julian-Enable/AURA)** — Planificador de rutas que calcula el clima esperado en cada tramo del viaje según la hora de llegada, no solo el clima actual del destino. Combina Google Maps, OpenWeather y OpenStreetMap con fallback automático entre servicios. React + TypeScript + Leaflet. [Demo en vivo](https://aur-a.netlify.app)

**[FarmAnalitics](https://farm-analitics.vercel.app)** — Dashboard de analítica para un POS farmacéutico real: sincroniza históricos desde SQL Server local, los sube a un backend en Railway y los sirve en un frontend Vue. Incluye mapa de calor de domicilios con geocodificación por lotes. FastAPI + Vue 3 + Parquet.

**[CancionEmocion](https://github.com/Julian-Enable/CancionEmocion)** — Detector de emociones a partir de la letra de una canción.

Todo lo demás está en mi [portafolio](https://juliangonzalez.vercel.app/).
